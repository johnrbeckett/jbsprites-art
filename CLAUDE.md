# jbsprites-art, standing rules

Read `~/Developer/CLAUDE.md` and `~/Developer/jbsprites/CLAUDE.md` first.

- Art only: source sheets, their grid JSON, override sources. No scripts, no cut sprites, no catalog; those live in jbsprites.
- jbsprites finds this repo as its sibling folder (`~/Developer/jbsprites-art`) or via `JBSPRITES_ART`.
- Never re-cut a published sheet that has no index (06 to 14); see jbsprites' CLAUDE.md.
- Replacing a sheet: move the old PNG to `~/Developer/Trash/` (dated folder), add the new one under the same name.
- Private repo. Push with a keyserver token, never stored in `.git/config`.
